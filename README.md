# Kova (concept by Anorix)

Kova is a concept site for a generic fintech wallet: send, spend and hold money across currencies from one app. It is a design/interaction showcase only; Kova is not a real financial institution and all people, numbers and quotes are fictional.

Built with Next.js, Tailwind CSS, three.js / React Three Fiber, GSAP ScrollTrigger and Lenis.

## Reference sites
- https://www.jeton.com/ (Awwwards SOTD, Jan 27 2025)

No code, copy, logos or images were taken from the reference. See CREDITS.md.

## Run
`npm install` then `npm run dev` (or `npm run build` + `npm start`).
